# SBC 304-2024 — Stage 21 slab-clause audit

## Scope
Stage 21 expands the SBC traceability map from chapter-level labels to the clause headings for one-way slabs (Chapter 7), two-way slabs (Chapter 8), strength reduction (21.2), sectional flexural strength (22.2–22.3), one-way and two-way shear (22.5–22.6), serviceability (24.1–24.4), and reinforcement details/development/splices (25.2, 25.4–25.5).

## Source and limitation
The official SBC 304-CC-2024 table of contents is available at:
https://sbc.gov.sa/ar/BC/Documents/tableofcontent2024/SBC%20304/SBC304_CC_241224-FA.pdf
The official SBC 304-2024 portal is available at:
https://sbc.gov.sa/En/BC/Pages/BuildingCode/BCDetails.aspx?codeId=304&year=2024

The first source is explicitly a **Code & Commentaries table of contents**. It confirms clause names and numbering, but not the full operative numerical provisions. Therefore all clause statuses in this stage are traceability states, not implementation claims. SBC design remains disabled and the section routine returns no design capacity.

## Key safeguards
- No equation has been enabled merely because its clause heading was located.
- No ACI or EC2 formula is presumed equivalent to SBC 304-2024.
- BS 8110 coefficients remain limited to the explicitly selected two-way slab analysis path and are not silently imported into the SBC code path.
- Release gate requires the exact applicable Code Requirements text, documented derivation and units, hand-calculation benchmark, edge-case tests, and independent review.

## Test status
Stage 21 tests verify clause-map coverage and fail-closed behavior. Passing software tests validates the software guardrails only; it does not establish code compliance.
