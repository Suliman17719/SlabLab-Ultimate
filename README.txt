SlabLab v0.3 – slab design: one-way, two-way, irregular (offline PWA)
Run locally:   python3 -m http.server 8080   then open http://localhost:8080 (service worker needs localhost or HTTPS)
Publish:       upload this whole folder to any static host with HTTPS (GitHub Pages, Netlify, Cloudflare Pages)
Install:       open the site on the phone, then  Android Chrome: Menu > Install app  |  iPhone Safari: Share > Add to Home Screen
After the first load the app works without internet.
Engines: engine.js (One Way Slabs) and engine2.js (Two Way + Irregular Slabs), mirroring Slabs_Design_EC2.xlsx. UI: app.js + style.css.


Audit Stage 8: Flexure audit includes iterative crack-control spacing, provided-steel moment resistance cross-check, and K-prime/neutral-axis limit check. See FLEXURE_AUDIT_STAGE8.md. Not construction-ready.
