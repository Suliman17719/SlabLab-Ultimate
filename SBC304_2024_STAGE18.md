# SBC 304-2024 — Stage 18 status

## What was added
- An independent `sbc304-2024-engine.js` module, separate from both EC2 and ACI.
- A machine-readable provision map for the slab-design areas relevant to SlabLab.
- Input-shape and numeric validation for future rectangular section calculations.
- A fail-closed result contract: it reports **NOT IMPLEMENTED** and never presents a guessed capacity or reinforcement result as an SBC design.
- Automated tests for provision-map entries, invalid input rejection, and fail-closed behavior.

## Official source used for the provision map
The Saudi Building Code portal lists SBC 304 as the Saudi Code for Concrete Structures. The official 2024 SBC 304 Code & Commentaries table of contents identifies Chapters 5–8 for loads, analysis, one-way slabs, and two-way slabs; Chapter 21 for strength-reduction factors; Chapter 22 for sectional flexure and one-/two-way shear; Chapter 24 for serviceability; and Chapter 25 for reinforcement detailing, development, and splices.

Official portal: https://sbc.gov.sa/En/BC/Pages/BuildingCode/BCDetails.aspx?codeId=304&year=2024
Official SBC 304-2024 Code & Commentaries contents: https://sbc.gov.sa/ar/BC/Documents/tableofcontent2024/SBC%20304/SBC304_CC_241224-FA.pdf

## Important limitation
A table of contents is not sufficient to verify equations, limits, exceptions, units, or Saudi-specific modifications. This stage therefore does not claim that SBC 304-2024 is identical to any ACI edition and does not enable SBC design in the user interface. The requirements document and applicable provisions must be checked before implementing calculation routines. Analysis method remains separate from concrete design-code checks; BS 8110 Table 3.14 coefficients remain confined to the explicitly identified two-way analysis route selected by the user.

## Not yet implemented
Load combinations; design strength and phi factors; flexural strength; minimum and maximum reinforcement; bar spacing; one-way shear; punching shear; deflection; crack/serviceability checks; development length; laps; detailing; and full report integration.
